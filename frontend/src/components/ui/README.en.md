# components/ui: presentational primitives

[中文](README.md) | [English](README.en.md)

## Responsibility

Components generated by [shadcn/ui](https://ui.shadcn.com) (`base-nova` style, built on Base UI) and adjusted as needed. They carry no business meaning: they take props, render DOM, and expose `data-slot` hooks for styling. Nothing more.

## Contents

| File | Description |
| --- | --- |
| `button.tsx` | `Button` component and the `buttonVariants` class recipe (variant × size). |
| `button.test.tsx` | Verifies default/custom variants, className merging and native prop forwarding. |

## Dependency direction

Depends only on `@/lib` (`cn`) and third-party UI libraries. **Never** imports `@/api`, screens or domain modules, and never fetches data.

## Conventions

- After `npx shadcn add <name>`, run `npm run format` and add JSDoc plus tests; the gate rejects the raw output.
- When a generated file is customized, record the divergence from upstream in its JSDoc so future regenerations can be diffed.
